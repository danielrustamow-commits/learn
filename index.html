1. Базовый шаблон приложения

Tkinter — стандартная библиотека Python для создания оконных приложений. Её не нужно устанавливать через pip, она идет в комплекте с Python.

Любое приложение строится по схеме: импорт → создание главного окна → добавление виджетов → запуск бесконечного цикла событий.

import tkinter as tk

# 1. Создаем главное окно
root = tk.Tk()
root.title("Мое первое окно")
root.geometry("400x300")  # Ширина x Высота

# 2. Добавляем текстовую метку
label = tk.Label(root, text="Привет, Tkinter!", font=("Arial", 16))
label.pack(pady=20)

# 3. Запускаем главный цикл обработки событий
root.mainloop()

2. Основные виджеты

Виджеты — это строительные блоки интерфейса (кнопки, поля ввода, текст).

tk.Label

Отображает статический текст или изображение.

Параметры: text, fg (цвет текста), bg (фон).

tk.Button

Кнопка, выполняющая функцию при нажатии.

Параметры: text, command=func.

tk.Entry

Однострочное поле для ввода текста.

Методы: .get() (получить), .delete(0, tk.END).

tk.Text

Многострочное текстовое поле (редактор).

Методы: .get("1.0", tk.END), .insert().

tk.Checkbutton

Флажок (чекбокс) с двумя состояниями.

Использует переменную tk.BooleanVar().

tk.Frame

Невидимый контейнер для группировки других виджетов.

Помогает строить сложные макеты.

3. Менеджеры геометрии (Размещение)

Чтобы виджет появился на экране, его нужно разместить одним из трех способов (не смешивайте pack и grid в одном контейнере!):

1. .pack() — Блочная упаковка

Размещает элементы друг за другом (сверху вниз или слева направо).

btn1.pack(side=tk.TOP, fill=tk.X, padx=10, pady=5)
btn2.pack(side=tk.LEFT)

2. .grid() — Табличная сетка (Самый популярный)

Разбивает окно на строки (row) и столбцы (column), начиная с 0.

label_name.grid(row=0, column=0, sticky="w") # Выравнивание по западу (левый край)
entry_name.grid(row=0, column=1, padx=5, pady=5)

3. .place() — Точные координаты

Размещает виджет по пикселям (x, y) или в долях (relx, rely).

btn.place(x=50, y=100) # Точно 50px слева и 100px сверху

4. Обработка нажатий и событий

Для простых кнопок используется параметр command. Для нажатий клавиш или кликов мыши — метод .bind().

import tkinter as tk

def on_click():
    user_text = entry.get()
    label.config(text=f"Вы ввели: {user_text}")

root = tk.Tk()
entry = tk.Entry(root)
entry.pack(pady=5)

btn = tk.Button(root, text="Нажми меня", command=on_click)
btn.pack(pady=5)

label = tk.Label(root, text="Ожидание ввода...")
label.pack(pady=5)

# Привязка клавиши Enter к функции
root.bind("<Return>", lambda event: on_click())

root.mainloop()
